# Protik

Günlük protein takibi ve protein hedefi asistanı.

## İlk sürümde olanlar

- Türkçe onboarding
- Kilo / aktivite / hedefe göre başlangıç protein hedefi
- Ana ekran ve günlük ilerleme
- 50 yiyeceklik başlangıç verisi
- Protein ekleme ve öğün seçimi
- Kalan proteine göre öneriler
- Profil ve hedef düzenleme
- Verilerin cihazda `localStorage` ile saklanması

## Çalıştırma

```bash
npm install
npm run dev
```

Sonra Vite'ın verdiği yerel adresi tarayıcıda aç.

> Not: Protein değerleri prototip içindir. Yayın öncesinde güvenilir tek bir besin veri kaynağı ile doğrulanmalıdır.
